# Правила проверки и оценивания

Каждый экзамен хранит ссылку на неизменяемую `ScoringRuleVersion`. Правило содержит предмет, период действия, пороги отметок 3/4/5, максимум первичного балла, порог геометрии и порог существенного расхождения экспертов. Пороги проверяются как монотонная шкала.

| Тип ответа | Проверка |
|---|---|
| Одиночный выбор | Сравнение одного нормализованного значения |
| Множественный выбор | Сравнение множества без повторов |
| Короткое число | `Decimal`; запятая и точка эквивалентны; нули в конце не меняют значение |
| Короткий текст | Настраиваемые strip, свёртка пробелов, casefold и Unicode NFKC |
| Развёрнутый | Только экспертная проверка по критериям |

Для чисел единица сравнивается отдельно и строго. Перевод единиц не выполняется без отдельного правила. Исходный ответ в `Answer` и его ревизиях остаётся неизменным; нормализованное значение хранится в `AutoCheckResult` вместе с ID и версией правила.

После двух независимых экспертных проверок баллы по критериям суммируются. Если разница не превышает `discrepancyThreshold`, итог задания — среднее двух баллов с округлением половины вверх. Иначе создаётся `ReviewDispute`; итог задаёт старший эксперт отдельным решением. Балл задания ограничен `0..maxScore`.

Итоговая отметка находится в `2..5`. Для математики при сумме баллов по геометрическим заданиям ниже `geometryMin` отметка становится 2, а `ResultVersion.reason` получает `GEOMETRY_MIN_NOT_MET`. При достижении порога действует обычная шкала. Пересчёт создаёт следующую версию результата; предыдущая версия остаётся доступной в истории.

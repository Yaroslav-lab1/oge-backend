# Безопасность учебного backend

Пароли хранятся как Argon2id hash с уникальной солью. Access JWT подписан серверным ключом и живёт не более 15 минут. Refresh токен — случайное opaque значение; в БД хранится только SHA-256. Обновление ротирует refresh, logout отзывает текущую refresh-сессию. После пяти неверных входов за десять минут вход блокируется на 15 минут.

Каждый защищённый маршрут проверяет роль, а сессия, ответ и результат дополнительно проверяют владение через назначение. Эксперт видит обезличенный ответ, может изменять лишь свою проверку в пределах lease и не может выполнять обе независимые проверки одной работы. Метрики выдаются только с отдельным токеном; BI — только роли `BI_SERVICE`.

Импорт ZIP ограничен 50 МБ с проверкой размера распаковки, числа файлов, коэффициента сжатия, каждого пути, типа записи, SHA-256 manifest и схемы предмета. Запрещены symlink, executable, внешние URL и найденные прямые персональные данные. Проверка PII эвристическая; перед реальным применением нужен отдельный процесс модерации контента.

Логи выводятся как JSON без тел запросов, ответов, токенов и полных КИМ. Аудит хранит безопасные атрибуты, UTC время, объект, действие и correlation ID; публичный API не изменяет события. Политика хранения — не менее 180 дней. В БД нужно ограничить права сервисного пользователя на изменение audit таблицы вне прикладных транзакций.

В production TLS 1.2+ завершается на reverse proxy; PostgreSQL и Redis доступны только из внутренней сети. Задайте случайные `JWT_SECRET` и `METRICS_TOKEN`, CORS allowlist, ограничение размера HTTP-запросов и резервное копирование. `.env` исключён из Git. Проверки безопасности и зависимостей запускаются в CI.

## Частота запросов и аудит

Квоты распределены между экземплярами через атомарный SQL upsert: refresh — 30/мин на IP соединения, audio — 10/мин на пользователя, answer — 120/мин на пользователя, export — 6/мин на пользователя. Login отдельно блокируется после пяти неудач. Клиент получает 429 и retryAfterSeconds; заголовки прокси не используются как доверенный IP. За reverse proxy требуется согласовать адресацию, чтобы несколько клиентов не делили один refresh-лимит.

Аудит защищён от UPDATE/DELETE и ORM, и триггером миграции. Прикладной API не удаляет события; AUDIT_RETENTION_DAYS по умолчанию 180. Внешняя архивная политика и мониторинг хранения относятся к стенду. Комментарии экспертов и тексты ответов в аудит не копируются.

## Проверка зависимостей

После обновления FastAPI, Starlette и PyJWT pip-audit не нашёл известных уязвимостей в закреплённом runtime-графе. Полный отчёт — dependency-audit.json. CI блокирует сборку при находках.

# Changelog

## 0.1.0-rc.2 — 2026-11-07

Устранены находки dependency audit, обновлены FastAPI/Starlette/PyJWT, усилена проверка длины секретов. 89 локальных тестов и отдельный PostgreSQL concurrency test проходят, coverage 81,58%, известных уязвимостей не найдено.

## 0.1.0-rc.1 — 2026-11-07

Первый кандидат учебного backend: роли и токены, версии КИМ, экзамены, ответы, аудио, проверка, результаты, аудит и аналитика; миграции, CI, тесты и документация.

Кандидат не принят для внешнего развёртывания: остаются уязвимости зависимостей и непроведённые эксплуатационные испытания. См. docs/implementation-status.md.

CI 42395589770 подтвердил миграции PostgreSQL, сборку/запуск контейнеров, сохранение ответа после рестарта API и backup/restore. Исправлены гонки назначения и завершения независимых экспертных проверок блокировкой общей строки сессии.
